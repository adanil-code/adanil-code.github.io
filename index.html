adanil-code/KmSharedPtr

Header-only C++20 lock-free shared pointers for Windows kernel drivers (x64 & ARM64, IRQL <= DISPATCH_LEVEL). Features DPC-based Quiescent State RCU, Epoch-based cache-aware Rundown with NUMA-sharded O(1) batch GC, and a 128-bit split-count atomic shared_ptr—eliminating per-object read-path RMWs and cache-line contention.

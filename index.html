Open Source Projects by adanil-code

A curated directory of open-source systems programming libraries, data structures, and high-performance string search implementations hosted on GitHub.

KmSharedPtr

Reference-counted smart pointer implementation designed for safe, deterministic memory management in kernel-mode and low-level systems environments.

Repository: github.com/adanil-code/KmSharedPtr

LRUHashTable

Combined hash table and doubly-linked list structure providing O(1) lookup, insertion, and Least Recently Used (LRU) cache eviction.

Repository: github.com/adanil-code/LRUHashTable

OptimisticCache

Concurrent caching implementation using optimistic synchronization techniques to minimize lock contention under read-heavy workloads.

Repository: github.com/adanil-code/OptimisticCache

StringPatternMatch

General-purpose pattern matching algorithms and utilities for fast substring and wildcard evaluation in C++ applications.

Repository: github.com/adanil-code/StringPatternMatch

KmStringPatternMatch

Kernel-compatible string pattern matching library supporting wildcard and structured sequence matching with predictable memory usage.

Repository: github.com/adanil-code/KmStringPatternMatch

KmStrSearch

Lightweight string searching utilities built for low-overhead environments without standard user-mode runtime dependencies.
